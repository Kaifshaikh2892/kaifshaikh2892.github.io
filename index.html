🔗 freegem - Run Gemini Locally as Your Own API

freegem is a small helper application that runs on your own Windows computer. It takes your existing Gemini web session and makes it available to other programs in a familiar, standard way. Instead of learning a new system, your existing tools can simply talk to freegem and get answers back.

It speaks three popular "languages" at once: the OpenAI-compatible format used by many chat apps and coding assistants, the Google-native format, and the MCP tool format used by modern AI agents. It also includes a careful web scraper and a research mode that shows you exactly where each answer came from.

✨ What freegem Does For You

You do not need to be a programmer to use freegem. If you can install an app and copy a link, you can run it. Here is what it gives you in plain terms:

  • One connection, many tools. freegem sits quietly on your machine and lets many different apps use your Gemini session at the same time.
  • OpenAI-compatible API. Apps that expect the OpenAI style of connection will work without changes. Just point them at freegem.
  • Google-native API. Tools built for Google's own format can connect too, using the same local address.
  • MCP tools. AI agents that use the Model Context Protocol can call freegem directly as a tool provider.
  • Guarded web scraper. freegem can read pages from the web on your behalf, but it does so with safety limits so it never runs away with your bandwidth or gets you blocked.
  • Cited research. When freegem researches a question, it returns the sources it used, so you can check the answers yourself.
  • Local and private. Everything runs on your computer. The bridge is not hosted somewhere else.

2 Save the download to your computer

On that page, look for the download area. Your browser will ask where to save the file. The easiest choice is your Downloads folder, because Windows opens it for you with one click. If your browser warns you about downloading, choose to keep the file.

3 Open the downloaded item

Press the Windows key and type Downloads, then press Enter. Find the item you just downloaded. If Windows shows a blue "Windows protected your PC" message, click More info and then Run anyway. This is a standard Windows message for apps downloaded from the internet.

4 Let freegem start

A small window will open and freegem will begin working. Keep this window open while you use it — closing it stops the bridge. You will see a local address printed in the window. That address is what other apps will use to talk to freegem.

5 Connect your first app

In whatever app you want to use with freegem, find its connection or "API" settings and paste in the local address shown in the freegem window. Choose the format that matches your app: OpenAI-compatible, Google-native, or MCP. Save the settings and send a test message.

Good to know: freegem is a bridge, not a separate AI model. It uses the Gemini web session that is already active on your computer, so make sure you are signed in to Gemini in your browser before you start.

🧭 Choosing the Right Connection Type

freegem offers three ways to connect. You only need one at a time, and you can switch later without reinstalling anything.

Connection type Best for
OpenAI-compatible API Chat apps, coding assistants, and any tool that already asks for an OpenAI-style address and key.
Google-native API Tools and scripts written specifically for Google's own request and response format.
MCP tools AI agents and assistants that support the Model Context Protocol and want to call freegem as a tool.

If you are unsure which one to pick, start with the OpenAI-compatible option. It is the most widely supported and the easiest to test.

🕸️ The Guarded Web Scraper

freegem can visit web pages and bring their contents back to your app. "Guarded" simply means it follows sensible limits: it waits politely between requests, it stops when a site asks it to slow down, and it will not crawl endlessly through a site.

  • Pages are fetched one at a time so your connection stays usable.
  • Requests respect the rules a website publishes for automated visitors.
  • Results are cleaned up so your app receives readable text instead of raw page clutter.
  • You stay in control — the scraper only runs when your app asks for it.

📚 Cited Research Mode

When you ask freegem to research something, it does not just hand you an answer. It gathers information, then returns the answer together with a list of the pages it used. Each point can be traced back to its source, so you can verify anything that looks surprising.

This is especially useful for work where accuracy matters: comparing products, checking facts, summarising articles, or preparing notes you plan to share with other people.

🛠️ Everyday Use and Troubleshooting

The window closed by itself

Reopen freegem the same way you opened it the first time. If it closes again immediately, make sure you are signed in to Gemini in your browser, then try once more.

My app cannot connect

Check that the freegem window is still open and that you copied the full local address, including the http:// part and the number at the end. Then confirm you selected the same connection type in your app that freegem is offering.

Answers are slow

freegem depends on the Gemini web session, so speed varies with how busy that service is. Try one request at a time if you are sending many at once.

I want to stop everything

Close the freegem window. Nothing keeps running in the background, and no settings on your computer are changed.

💡 Tips for a Smooth First Run

  • Keep your browser signed in to Gemini before opening freegem.
  • Leave the freegem window visible while you test, so you can read any messages it prints.
  • Test with a short, simple question first. Once that works, try longer tasks.
  • Use the cited research option when you need to check where information came from.
  • Only run one connection type per app to avoid confusion.

❓ Questions People Ask

Do I need to know how to code?

No. You download it, open it, and paste a local address into whichever app you want to use. The coding only matters if you choose to write your own scripts later.

Does freegem replace Gemini?

No. It works alongside your Gemini web session and simply makes that session usable by other programs on your computer.

Is anything sent to a third party?

The bridge runs locally on your machine. Requests go from your apps to freegem on your own computer, and out to the web only when you ask for scraping or research.

Can I use more than one app at once?

Yes. freegem is built to serve several apps at the same time through the same local address.
